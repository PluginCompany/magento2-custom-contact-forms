# Custom Contact Form Front-end Examples

Below you'll find front-end examples of the various contact forms display options.

## <a id="form-page"></a>Contact Form Page

Example of custom contact form in an automatically created form page.

![magento 2 contact form page](images/M2-ContactForms12-1.png)

## <a id="embedded-form"></a>Contact Form Embedded in Page

Example of custom contact form embedded in a store page using the [contact form widget](./16-creating-custom-contact-form-widgets.md#embedded-widget).

![contact from embedded in page](images/M2-ContactForms12-2.png)

## <a id="layout-form"></a>Contact Form Embedded in Product Page

Example of a product questions form embedded in a product page by adding the contact form widget to a [specific layout update](./16-creating-custom-contact-form-widgets.md#layout-widget).

![product questions form in magento 2 product page](images/M2-ContactForms12-3.png)

## <a id="sidebar-widget"></a>Contact Form Sidebar Widget

Example of a [sidebar widget](./17-widget-options.md#pop-up-widget) with contact button, which displays the contact form in a pop-up when clicked on.

![contact form sidebar widget](images/M2-ContactForms12-4.png)

## <a id="pop-up-form"></a>Pop-up Contact Form

Example of custom contact form shown in a light-box pop-up using the [pop-up form widget](./17-widget-options.md#pop-up-widget).

![magento 2 pop-up form](images/M2-ContactForms12-5.png)

## <a id="slide-out-form"></a>Slide-out Contact Form

Example of the a form appearing from the left side of the front-end store using a [slide-out form widget](./17-widget-options.md#slide-out-widget).

![magento 2 slide-out form](images/M2-ContactForms12-6.png)

## <a id="multipage"></a>Multi-page Contact Form

Example of multi-page contact form, which is divided into multiple pages or tabs with the [Form Page](./07-form-builder.md#form-page) component. The top navigation bar automatically adjusts to smaller resolution screens if the form page titles don't fit on one line.

![magento 2 multi-page form](images/M2-ContactForms12-7.png)

## <a id="multicolumn"></a>Multi-column Contact Form

Example of multi-column contact form, which is divided into multiple sections and columns using the [Form Section](./07-form-builder.md#form-section) component.

![magento 2 multi-column form](images/M2-ContactForms12-8.png)
